## Claude Operating Rules

- Work only on the phase explicitly assigned in the current prompt.
- Do not implement future phases.
- Inspect the existing repository before changing files.
- Preserve existing work unless the assigned phase requires modification.

- Keep the project buildable.
- Verify changes before reporting completion.
- Never claim a test passed unless it was actually run.
- Report blockers and limitations honestly.
- Do not use force-push.
- Do not rewrite Git history.
- Do not silently expand scope.
