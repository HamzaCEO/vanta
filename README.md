# VANTA

VANTA is a fictional premium architecture studio website built around an immersive, scroll-controlled 3D architectural journey.

The project is intentionally more than a Three.js demonstration. The cinematic journey introduces the studio's architectural point of view, then continues into design principles, selected concept studies, studio positioning, and a commission path.

## Stack

- Next.js 16
- React 19
- TypeScript
- React Three Fiber
- Three.js
- Drei
- CSS Modules
- pnpm

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm typecheck
pnpm lint
pnpm build
git diff --check
```

## Product structure

1. Cinematic architectural journey
2. Point of view
3. Design principles
4. Selected concept studies
5. Studio
6. Commission

The 3D journey remains the signature interaction. It is not treated as a decorative background.

## Status

The original 7-phase 3D foundation is complete. CP8 is the product re-architecture pass that turns that technical foundation into a coherent architecture-studio website.

Concept projects in the current content model are fictional and are explicitly labelled as concept studies.
