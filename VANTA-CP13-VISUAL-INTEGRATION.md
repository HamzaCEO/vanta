# VANTA — CP13 Visual Integration

## Purpose

Connect the end of the cinematic 3D experience to the editorial website so the transition feels like a deliberate continuation of the same architectural narrative rather than a hard switch from WebGL to ordinary content.

## Changes

- Added `ExperienceExit` as the first section after the fixed cinematic track.
- Added a visual and semantic handoff from the final reveal into the studio's point of view.
- Added direct actions into Work and Studio instead of leaving the visitor at a dead end.
- Reused VANTA's existing tokens, typography, line system, spacing language, and restrained palette.
- Added responsive behavior without introducing new dependencies or animation libraries.
- Preserved the existing R3F scene, native scroll system, project system, commission flow, and pnpm dependency model.

## Intent

The 3D journey now has a clear consequence: the visitor reaches a statement explaining what the journey represented, then can continue into the architectural studies or the studio method.
